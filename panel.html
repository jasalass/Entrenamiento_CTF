Tu entrenamiento local

8 retos por día durante 30 días (uno de cada enfoque clásico), seguidos de 12 días de explotación de binarios real y 8 de reversing a ciegas — 260 retos en total, dificultad creciente. Trabaja los archivos de cada reto desde tu Kali (las rutas están dentro de cada tarjeta), y cuando tengas la flag, pégala aquí para validarla. Tu progreso se guarda solo en este navegador.

Objetivo del entrenamiento: no se trata de memorizar comandos. Se trata de aprender a pasar de una observación a una hipótesis, comprobarla con una herramienta y decidir qué hacer después.
📘 Cómo pensar un CTF (léeme primero)

La pregunta central de cualquier reto es: ¿qué evidencia tengo y qué hipótesis puedo comprobar con ella? Evita convertir el CTF en una lista de comandos que ejecutas por costumbre.

1 · Observación¿Qué tengo realmente? Archivo, bytes, respuesta HTTP, binario, servicio, metadatos.
2 · Hipótesis¿Qué podría explicar lo que estoy viendo? Formula una idea concreta.
3 · PruebaElige la herramienta que pueda confirmar o descartar esa idea.
4 · InterpretaciónNo basta con obtener una salida: decide qué significa y qué nueva pista aporta.
5 · Siguiente pasoRepite el ciclo hasta llegar a la flag. No ejecutes técnicas sin una razón.
  1. Reconoce, no adivines. Mira qué tienes: file, strings, xxd, editor o navegador. El formato y los bytes dan evidencia.
  2. Codificar ≠ cifrar. Base64, hex y binario representan datos; César, Vigenère y XOR transforman datos con una lógica que debes invertir. Un hash no se "descifra".
  3. Piensa en capas. Si una salida parece otra representación de datos, decodifica esa capa y vuelve a observar antes de decidir la siguiente técnica.
  4. Invierte la operación. En reversing y crypto, identifica primero la transformación. Si hay varias, reconstruye el orden y aplícalo al revés.
  5. Todo lo del cliente es observable. En web, HTML, JavaScript, cookies y peticiones forman parte de la superficie que el reto te permite estudiar.
  6. Documenta. Registra observaciones, hipótesis, comandos usados y resultados. Una salida aparentemente inútil puede explicar la siguiente etapa.
Error típico: lanzar gobuster, sqlmap, binwalk o cualquier otra herramienta "porque sí". Primero explica qué quieres descubrir; después elige cómo comprobarlo.

🔧 Cómo usar las herramientas (referencia con ejemplos)

Esta sección es una referencia, no una receta. Para cada herramienta intenta responder primero: ¿qué quiero descubrir?, ¿por qué esta herramienta me ayuda?, ¿qué resultado espero? Luego ejecuta el comando y aprende a interpretar su salida.

AntesDefine la pregunta.
DuranteObserva la salida, no solo si "funcionó".
DespuésConvierte el resultado en una nueva hipótesis.
Crypto / Encoding
base64 · basenc · xxd · tr · rev — codificaciones en terminal
base64 -d ARCHIVO

-d = decode. Sin -d, codifica.

Ej. base64 -d mensaje.b64 · codificar: printf admin | base64 → YWRtaW4=

basenc --base32 -d ARCHIVO

Decodifica Base32. También --base16, --base64, --base85.

Ej. basenc --base32 -d fuente_1.txt

xxd ARCHIVO

Volcado hex (offset | hex | ASCII) para inspeccionar bytes.

Ej. xxd foto.png | tail → ver datos adjuntos tras el EOF.

xxd -r -p ARCHIVO

Revierte hex a bytes. -r reverse, -p plain (hex continuo).

Ej. xxd -r -p datos.hex → texto con la flag.

tr 'A-Za-z' 'N-ZA-Mn-za-m'

Aplica ROT13 (mapea cada letra 13 posiciones).

Ej. cat frag.txt | tr 'A-Za-z' 'N-ZA-Mn-za-m'

rev

Invierte una cadena (útil si una capa está al revés).

Ej. echo 46414c47 | rev → 74414c6164

hashid · hashcat · john — identificar y crackear hashes
hashid ARCHIVO

Identifica el algoritmo por el formato del hash.

Ej. hashid hash.txt → "MD5".

hashcat -m 0 -a 3 ARCHIVO ?l?l?l?l

-m 0 MD5 (100=SHA1, 1400=SHA256). -a 3 máscara. ?l minúscula, ?u mayúscula, ?d dígito, ?a todo.

Ej. hashcat -m 0 -a 3 hash.txt ?l?l?l?l → palabra de 4 minúsculas.

hashcat -m 0 -a 0 ARCHIVO DICCIONARIO

-a 0 = diccionario (prueba cada palabra del archivo).

Ej. hashcat -m 0 -a 0 hash.txt /usr/share/wordlists/rockyou.txt

john --format=raw-md5 --mask='?l?l?l?l' ARCHIVO

Mismo ataque con John; también --wordlist=. Ver resultado con --show.

Ej. john --format=raw-md5 --mask='?l?l?l?l' hash.txt ; john --show hash.txt

xortool · RsaCtfTool · openssl · python+sympy — XOR y RSA
xortool ARCHIVO

Estima la longitud y la clave probable de un XOR repetido. -c ' ' asume que el byte más común del texto es el espacio.

Ej. xxd -r -p cifrado.hex > ct.bin ; xortool ct.bin -c ' '

RsaCtfTool -n N -e E --uncipher C

Factoriza n, deriva d y descifra c automáticamente.

Ej. RsaCtfTool -n 47053 -e 17 --uncipher 12345

python3 -c "import sympy;print(sympy.factorint(N))"

Factoriza n (para RSA con módulo pequeño).

Ej. python3 -c "import sympy;print(sympy.factorint(47053))" → {211:1, 223:1}

d=pow(e,-1,phi) ; m=pow(c,d,n)

Con p,q: phi=(p-1)*(q-1), luego clave privada d y descifrado m.

Ej. python3 -c "p,q,e,c=211,223,17,X;phi=(p-1)*(q-1);d=pow(e,-1,phi);print(pow(c,d,p*q))"

openssl passwd -6 CLAVE

Genera un hash de contraseña (formato /etc/shadow).

Ej. openssl passwd -6 toor → úsalo al editar /etc/passwd.

Stego / Forense
file · strings · grep · wc — primer vistazo
file ARCHIVO

Pregunta que responde: "¿Qué tipo de datos tengo realmente?" Usa firmas internas (magic number), no confíes en la extensión.

Ej. file datos.bin → "data" (binario crudo).

strings ARCHIVO

Pregunta que responde: "¿Hay texto legible incrustado?" Extrae cadenas imprimibles. Si aparece una URL, nombre, mensaje o fragmento de flag, úsalo como evidencia para el siguiente paso.

Ej. strings foto.png | tail

strings ARCHIVO | grep -i flag

grep -i ignora mayúsculas, -a binario como texto, -A1 una línea después.

Ej. strings datos.bin | grep -i flag

wc -c ARCHIVO

Cuenta bytes; sirve para sospechar contenido invisible.

Ej. wc -c nota.txt → pesa más de lo que ves (zero-width).

exiftool — metadatos
exiftool ARCHIVO

Pregunta que responde: "¿El archivo contiene información descriptiva que no veo a simple vista?" Revisa campos como Comment, Author o Artist, pero no asumas que cualquier metadato es la flag.

Ej. exiftool postal.png → campo Comment con la flag.

exiftool -CAMPO ARCHIVO

Muestra solo un campo.

Ej. exiftool -Comment postal.png

binwalk · foremost · zcat · unzip — archivos embebidos y comprimidos
binwalk ARCHIVO

Pregunta que responde: "¿Hay otra estructura o archivo escondido dentro de estos bytes?" La salida y sus offsets indican qué evidencia merece ser extraída o inspeccionada.

Ej. binwalk captura.dat → "Zip archive data".

binwalk -e ARCHIVO

-e extrae a _ARCHIVO.extracted/. -Me recursivo.

Ej. binwalk -e captura.dat → dentro aparece flag.txt.

foremost ARCHIVO

Carving por firmas a la carpeta output/.

Ej. foremost backup.bin -o salida

zcat / unzip

zcat descomprime gzip a pantalla; unzip abre ZIP (-l lista).

Ej. zcat backup.gz · unzip flag.zip

zsteg · stegsolve — LSB en imágenes
zsteg IMG.png

Prueba las combinaciones LSB comunes en PNG/BMP.

Ej. zsteg imagen.png

zsteg -a IMG.png

-a = todas (todos los canales y planos de bits).

Ej. zsteg -a imagen.png → línea tipo b1,r,lsb,xy ... text: "FLAG{..."

zsteg -E 'b1,rgb,lsb,xy' IMG.png

-E extrae exactamente ese plano/canal.

Ej. zsteg -E 'b1,r,lsb,xy' imagen.png

stegsolve (GUI): abre la imagen, recorre los planos con las flechas, y Analyse ▸ Data Extract marcando R/G/B + LSB.

steghide · pngcheck — stego en JPG y estructura PNG
steghide extract -sf IMG.jpg

Extrae datos ocultos con steghide (JPG/BMP/WAV). Pide passphrase: prueba vacía (Enter) o la que insinúe el reto.

Ej. steghide extract -sf foto.jpg · ver si hay algo: steghide info foto.jpg

pngcheck -v IMG.png

Valida la estructura del PNG y lista sus chunks; delata chunks raros o datos pegados tras el fin (IEND).

Ej. pngcheck -v foto.png → avisa de "additional data after IEND".

Reversing
gcc · make — compilar
make

Compila usando el Makefile incluido (genera ./check).

Ej. make && ./check → imprime la flag.

gcc FUENTE.c -o SALIDA

Compila a mano si no hay Makefile.

Ej. gcc check.c -o check && ./check

radare2 · gdb · ltrace · strace · objdump — analizar binarios
r2 -AA ./bin

Pregunta que responde: "¿Qué lógica implementa este binario?" Empieza buscando funciones, strings y el flujo de main; la meta es reconstruir la comprobación, no leer cada instrucción.

Ej. r2 -AA ./check → pdf @ main

ltrace ./bin

Traza llamadas a librería; revela comparaciones (p. ej. strcmp con la clave).

Ej. ltrace ./check miClave

strace ./bin

Traza syscalls (open, read, execve).

Ej. strace -f ./check

objdump -d ./bin

Desensambla (-d). -s -j .rodata vuelca constantes.

Ej. objdump -d ./check | less

gdb ./bin

Depura: break main, run, ni/si, info registers.

Ej. gdb ./check → break main → run

python3 -c "..."

Invertir la transformación leída en el fuente, sin compilar.

Ej. python3 -c "d=[0x55,0x5e];print(bytes(b^0x13 for b in d))"

rabin2 · ghidra — info del binario y decompilador
rabin2 -I ./bin

Información del binario: arquitectura, bits, protecciones (NX, PIE, canary). -z strings, -s símbolos. (viene con radare2).

Ej. rabin2 -I ./check · rabin2 -z ./check

ghidra

Decompilador gráfico (NSA): importa el binario, autoanaliza y lee el pseudo-C de cada función. Lo mejor para lógica compleja.

Ej. abre Ghidra → File ▸ Import check → doble clic en main.

Web
nmap — descubrir puertos y servicios
nmap -sCV -p- IP

Pregunta que responde: "¿Qué superficie de servicio expone la máquina del laboratorio?" Primero identifica puertos y versiones; después decide qué servicio merece investigación.

Ej. nmap -sCV -p- 127.0.0.1 → 8001/http.

nmap -p PUERTO -sV IP

Escaneo rápido de un puerto conocido.

Ej. nmap -p 8001 -sV 127.0.0.1

curl — hacer peticiones HTTP
curl -s URL

Pregunta que responde: "¿Qué me entrega realmente el servidor?" Inspecciona cuerpo, cabeceras, redirecciones y respuestas antes de intentar explotar nada.

Ej. curl -s http://127.0.0.1:8001/robots.txt

curl -b "k=v" URL

Envía una cookie.

Ej. curl -b "auth=YWRtaW4=" http://127.0.0.1:8002/panel

curl --data 'a=b' URL

POST (formulario). --data-urlencode codifica valores con espacios/símbolos.

Ej. curl --get --data-urlencode "id=0 UNION SELECT id,flag FROM secret" http://IP:8007/item

gobuster · ffuf · jwt_tool · sqlmap — enumeración y explotación web
gobuster dir -u URL -w LISTA

Fuerza bruta de rutas con un diccionario (-w).

Ej. gobuster dir -u http://127.0.0.1:8001 -w /usr/share/wordlists/dirb/common.txt

ffuf -u URL/FUZZ -w LISTA

Igual que gobuster; FUZZ es el marcador que se sustituye.

Ej. ffuf -u http://127.0.0.1:8001/FUZZ -w /usr/share/wordlists/dirb/common.txt

jwt_tool TOKEN

Decodifica header/payload. -X a ataque alg:none (firma vacía).

Ej. jwt_tool $(cat token.txt) -X a → token forjado de admin.

sqlmap -u URL --data 'u=a&p=a' --dump

Detecta y explota SQLi; --dump vuelca datos, -T una tabla, --batch sin preguntar.

Ej. sqlmap -u http://IP:8006/ --data 'user=a&pass=a' --dump -T users --batch

whatweb · nikto — fingerprint y escaneo del sitio
whatweb URL

Identifica tecnologías: servidor, framework, lenguaje, versiones. Primer paso tras descubrir un web.

Ej. whatweb http://127.0.0.1:8001

nikto -h URL

Escáner de vulnerabilidades y archivos/rutas conocidas (configuraciones, backups, cabeceras inseguras).

Ej. nikto -h http://127.0.0.1:8001

Burp Suite — proxy para interceptar/repetir

Configura el navegador para usar Burp como proxy (127.0.0.1:8080). Intercepta peticiones, mándalas a Repeater para modificarlas y reenviarlas (cookies, parámetros, cabeceras). Alternativa gráfica a curl.

Pwn / Escalada
ssh — entrar a la máquina
ssh USUARIO@IP -p PUERTO

Conecta por SSH; acepta la huella con yes la primera vez.

Ej. ssh ctf@127.0.0.1 -p 8101 (contraseña: ctf)

find · sudo -l · getcap — buscar vías de escalada
find / -perm -4000 -type f 2>/dev/null

Pregunta que responde: "¿Qué programas pueden ejecutarse con privilegios distintos a los míos?" Después de encontrar uno, investiga por qué es interesante antes de intentar usarlo.

Ej. encuentra /usr/local/bin/runner → ejecútalo → shell root.

sudo -l

Qué puedes correr como root por sudo; busca cada binario en GTFOBins.

Ej. sudo -l → (root) NOPASSWD: /usr/bin/find

getcap -r / 2>/dev/null

Lista capabilities. Peligrosas: cap_setuid, cap_dac_read_search.

Ej. getcap -r / 2>/dev/null → python3cap cap_setuid+ep

linpeas · pspy · GTFOBins · gcc — enumerar y explotar
./linpeas.sh

Enumera automáticamente todas las vías de escalada; resalta lo explotable.

Ej. súbelo a la máquina y ./linpeas.sh | less -r

./pspy64

Observa procesos y cron en vivo sin ser root.

Ej. ./pspy64 → ves a root ejecutar /opt/backup.sh cada minuto.

GTFOBins

Catálogo gtfobins.github.io: dado un binario con sudo/SUID/cap, da el comando exacto para escalar.

Ej. find (sudo): sudo find . -exec /bin/sh \; -quit

gcc -fPIC -shared -o e.so e.c -nostartfiles

Compila una librería para LD_PRELOAD (con constructor que da shell).

Ej. sudo LD_PRELOAD=/tmp/e.so id → shell root.

Plataforma (levantar máquinas)
docker compose — arrancar/parar una máquina del lab
docker compose -f RUTA/docker-compose.yml up -d --build

Construye y arranca el contenedor en segundo plano (-d). El primer build tarda.

Ej. cd lab/machines/d01-web && docker compose up -d --build

docker compose ... down

Detiene y elimina el contenedor al terminar.

Ej. docker compose down (o el botón «Detener» del panel).
